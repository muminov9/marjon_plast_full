# Marjon Plast Business v5

Full-stack biznes boshqaruv dasturi: Express backend + JSON database + JWT auth + roles + customers/debts + products + suppliers + raw materials + production + workers/payroll + sales + purchases + cash + reports + Excel/PDF + audit log.

## Windows
1. Node.js 20+ o‘rnating.
2. Papkada terminal oching.
3. `npm install`
4. `.env.example` nusxasini `.env` qiling va JWT_SECRET ni o‘zgartiring.
5. `npm run seed` — demo ma’lumot va `admin / admin123` yaratadi.
6. `npm start`
7. `http://localhost:3000` ni oching.

## Production
JSON database kichik biznes/demo uchun qulay. Katta ko‘p foydalanuvchili production uchun PostgreSQL ga ko‘chirish tavsiya etiladi. HTTPS va kuchli JWT_SECRET ishlating.
